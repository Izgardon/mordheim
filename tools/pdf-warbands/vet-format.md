# The vet file

What a batch agent writes for William (`.pdf-sources/work/batch-N-for-william.md`), in the shape of batch 6's
`batch-6-for-william.md`. He reads the decisions and answers them; everything else is there to check against.
Plain words, no fluff, and the same "our own words" rule as the source files.
