Grades, settings and warband types

A list of warband types with their grade, setting and link; settings that carry a grade; and how a campaign chooses what is in play. Cut back to what we agreed. The bestiary rewrite has its own plan and comes first.

Plan only, nothing built Updated 22 Oct 2026 Builds after the bestiary rewrite

Agreed so far

  • Grades are 1a, 1b, 1c, 2a, 2b and 3. Rulebook content is 1a; there is no "core".
  • Mordheim and "No setting" are real settings. Every setting has a grade, and picking the campaign's grade selects the settings at or below it. The 1b and 2a warbands without a setting belong to Mordheim; "No setting" (grade 3) holds the grade-3 web warbands.
  • For now: a list of warband types (name, grade, setting, link) with no parsing, and a grade on the catalogue rows we already have.
  • Raising a warband uses the searchable warband type picker as mocked. The type's link fills the existing warband link field, which the player can replace.

What the research found

  • 162warband types

    Broheim is the complete list. It has 162 warbands across grades 1a to 3, each with a source code and a PDF link. That is everything the list needs.

  • 75on mordheimer

    mordheimer.net adds settings and nicer links. Its warband index gives a setting for 75 of them, and a page that reads better than a PDF. Its catalogue data tags every item, skill and spell with a grade and a setting.

  • 209/216items match

    Our catalogue already came from mordheimer, so grading what we have is a name lookup: items 209 of 216, spells 164 of 167. The few misses are checked by hand.

Settings carry a grade

A setting is the world or supplement a warband belongs to. Every setting has its own grade, taken from mordheimer's menu badges and, for Broheim-only supplements, from their warbands. When an owner picks the campaign's grade, every setting at or below it is selected, and they can then add or remove settings by hand.

One question is left: what happens inside a selected setting that has warbands above the campaign's grade? Lustria is a 1b setting but also holds four 2b supplement warbands, and Khemri (1b) holds eight grade-3 ones. Rule C trims each setting to the higher of the campaign's grade and the setting's own grade, so Lustria at 1c brings its 1b warbands but not its 2b ones, while a 2b setting added by hand still brings all of its warbands. Rule A lets a selected setting bring everything in it.

Recommendation: Rule C. It keeps the campaign's grade meaningful inside every setting (a 1c campaign doesn't suddenly get Khemri's grade-3 drafts), while a supplement added on purpose still brings its own warbands.

Two new tables (grades and warband types) and a grade on settings. The settings themselves use pass 5's empty campaign_type table and the campaign's pivot to it. Every catalogue table already has a nullable campaign_type_id, so grading what we have is one new column.

Raising a warband

Agreed. The free-text Faction field becomes a searchable warband type picker. Picking a type fills the warband link field that already exists on the form; the player can replace it with their own link or clear it.

Today

  • "Faction" is free text, so "Skaven", "skaven" and "Clan Eshin" are three factions
  • No grade, and the link field starts empty
  • Can't be changed after creation

Agreed

  • "Warband type": a search over the list, with grade and setting on each row
  • Types outside the campaign's settings or grade are listed greyed out. Picking one shows a warning, and it goes through
  • "Add a custom warband type" creates one for this campaign, which other players there can pick too
  • The type's link fills the warband link field, which stays editable. The type can be changed later in Settings → Personal

How the data gets in

One snapshot of two listing pages and one JSON bundle, merged by a script into seed files we commit and review as a git diff. The seeders then load them as they do today. Nothing is fetched at runtime and nothing is parsed out of PDFs.
